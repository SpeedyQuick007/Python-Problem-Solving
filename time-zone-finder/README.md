# 🌍 Time Zone Finder

This program takes a time as input and returns the possible time zones and timeline names that match it. It calculates the offset from GMT based on the provided local time.

## Features
- Uses the `datetime` library to handle time and date.
- Converts input time to corresponding time zones using a predefined dictionary of GMT offsets.

## How to Use
1. Run the program.
2. Enter the current time in 24-hour format (HH:MM) when prompted.
3. The program will calculate the GMT offset and return the corresponding time zone name.

## Skills Used
- Working with time and date
