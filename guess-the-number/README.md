# 🎯 Guess The Number

A Python game where the computer selects a random number between 1 and 100, and you try to guess it!

## Features
- Random number generation
- Input validation
- Feedback on guesses

## How to Play
1. Run the game: `python guess_the_number.py`
2. Enter your guess when prompted.
3. Keep guessing until you find the correct number!

## Skills Used
- Loops
- Conditionals
- Input/Output
